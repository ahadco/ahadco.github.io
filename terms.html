الشروط والأحكام

باستخدام موقع عهد أو إرسال طلب أولي، يقر المستخدم بأنه بالغ وأن المعلومات التي يقدمها صحيحة بقدر علمه، وأن غرضه من الخدمة هو التعارف الجاد المؤدي إلى الزواج ضمن الحدود الشرعية والنظامية المطبقة.

طبيعة الخدمة

عهد خدمة للتوفيق والترشيح وإدارة رحلة التعارف الجاد. لا تضمن الخدمة وجود تطابق مناسب، ولا تضمن قبول أي طرف للآخر، ولا تضمن إتمام الزواج.

الزواج الرسمي والمسيار

يمكن للمستخدم تحديد تفضيله للزواج الرسمي أو المسيار. ويظل استيفاء الأحكام الشرعية والمتطلبات النظامية مسؤولية الأطراف وفق حالتهم والجهات المختصة. لا تمثل عهد جهة إفتاء أو مكتب محاماة أو جهة توثيق عقد.

السلوك المقبول

يحظر استخدام الخدمة للتحرش أو الابتزاز أو الاحتيال أو طلب محتوى غير لائق أو انتحال الهوية أو جمع بيانات الآخرين أو استخدامها خارج غرض التوافق والزواج. ويجوز تقييد أو إيقاف الحسابات أو الطلبات عند الاشتباه في إساءة الاستخدام.

الخصوصية والموافقة

لا يحق للمستخدم نشر أو إعادة توزيع صور أو معلومات أو محادثات تخص طرفًا آخر دون موافقته. يجب احترام قرار الرفض أو إيقاف التواصل فورًا.

السلامة

ننصح بعدم إرسال الهوية الوطنية أو بيانات الحسابات البنكية أو كلمات المرور أو التحويلات المالية إلى أشخاص تم التعرف عليهم عبر الخدمة. أي لقاء حضوري يجب أن يراعي السلامة والخصوصية والظروف المناسبة.

الحسابات والمحتوى

يتحمل المستخدم مسؤولية حماية بيانات دخوله والمحتوى الذي ينشره. قد تزال المواد المخالفة أو التي تعرض الآخرين للخطر أو تنتهك حقوقهم.

التعديلات

قد تتغير هذه الشروط مع تطور الخدمة. يظهر تاريخ آخر تحديث أعلى الصفحة، ويعد استمرار الاستخدام بعد نشر النسخة المحدثة قبولًا لها بالقدر الذي يسمح به النظام المطبق.

تنبيه

هذه نسخة تشغيلية عامة وليست بديلًا عن مراجعة قانونية متخصصة قبل التوسع التجاري أو إضافة المدفوعات أو العقود الملزمة.
