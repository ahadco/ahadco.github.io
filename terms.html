الشروط والأحكام

تنظم هذه الشروط استخدام «الخطّابة عهد · AHAD»، وهي خدمة خاصة للتوفيق للزواج الجاد. استخدام الخدمة يعني الالتزام بالاحترام والصدق والخصوصية وعدم إساءة استخدام بيانات أو صور أو وسائل التواصل الخاصة بالآخرين.

1. الأهلية

الخدمة للبالغين 18 سنة فأكثر. يجب تقديم معلومات صحيحة قدر الإمكان، وعدم انتحال شخصية الغير أو إنشاء حسابات مضللة. تحتفظ عهد بحق رفض أو تعليق الطلبات التي تبدو غير جادة أو مخالفة للسلامة أو النظام.

2. طبيعة الخدمة

عهد تساعد في الاكتشاف والترشيح والمراجعة البشرية والتعارف الموجّه. لا تضمن وجود مرشح مناسب، ولا تضمن القبول المتبادل أو إتمام الزواج أو استمراره. القرار النهائي مسؤولية كل طرف.

3. مسارات الزواج

يمكن للخدمة دعم الزواج الرسمي أو المسيار حيث يكون ذلك مشروعًا ومستوفيًا للمتطلبات الشرعية والنظامية ذات الصلة. عهد ليست جهة إفتاء أو محاماة أو توثيق زواج، وعلى المستخدمين التحقق من الأحكام والمتطلبات التي تنطبق عليهم.

4. الاعتماد قبل الظهور

إنشاء بيانات حساب لا يمنح حق الدخول إلى Discover تلقائيًا. قد يتطلب الملف مراجعة واعتماد فريق عهد، ويمكن تعليق أو رفض الاعتماد لحماية المجتمع أو عند عدم اكتمال المتطلبات.

5. السلوك المقبول

يُمنع التحرش، الابتزاز، الإساءة، إرسال محتوى جنسي صريح، طلب المال أو التحويلات المشبوهة، التهديد، جمع بيانات المستخدمين، مشاركة بيانات شخص دون إذنه، التحايل على الحظر، أو استخدام الخدمة لعلاقات عابرة تتعارض مع الغرض المعلن.

6. الخصوصية والسرية

يجب احترام حدود الطرف الآخر وعدم تصوير المحادثات أو إعادة نشر الصور أو البيانات الخاصة دون موافقة واضحة. ظهور معلومة داخل الخدمة لا يمنح ترخيصًا لاستخدامها خارج غرض التوفيق.

7. التحقق والهوية

قد تضيف عهد إجراءات تحقق إضافية للحسابات أو الموظفين أو الحالات الجادة. رمز «موثق» إن ظهر يعني اجتياز نوع محدد من التحقق داخل الخدمة ولا يمثل ضمانًا للسلوك أو الملاءة أو الصدق الكامل.

8. الترشيحات والتقارب

أي وصف مثل «تقارب أولي مرتفع» هو إشارة إرشادية مبنية على معلومات الملف والتفضيلات، وليس تقييمًا نفسيًا أو علميًا دقيقًا ولا ينبغي اتخاذ قرار الزواج بناءً عليه وحده.

9. المحادثات والتواصل

المحادثات تُتاح وفق قواعد المنتج مثل التوافق المتبادل. يحتفظ كل طرف بحق إيقاف التواصل أو الحظر أو الإبلاغ. المكالمات المباشرة غير مفعلة في الإطلاق الأساسي حتى يتم توفير بنية اتصال مناسبة للخصوصية والأمان.

10. المحتوى المرفوع

يحتفظ المستخدم بحقوقه في المحتوى الذي يرفعه، ويمنح عهد ترخيصًا محدودًا بالقدر اللازم لتخزينه ومعالجته وعرضه داخل الخدمة وفق إعدادات الخصوصية. يجب ألا يرفع المستخدم محتوى لا يملك حق استخدامه أو محتوى غير قانوني أو ضار.

11. الإبلاغ والإيقاف

يمكن الإبلاغ عن سلوك مقلق. قد تقوم عهد بتقييد الحساب أو تعليقه أو إغلاقه لحماية المستخدمين أو التحقيق في إساءة أو امتثالًا لطلب نظامي. يمكن طلب مراجعة القرار عبر فريق عهد عندما تكون قناة المراجعة متاحة.

12. الأمان

المستخدم مسؤول عن حماية بيانات دخوله وعدم مشاركة كلمة المرور أو رموز التحقق. فريق عهد لن يطلب كلمة المرور عبر المحادثات. يجب الإبلاغ عن أي اشتباه في اختراق الحساب فورًا.

13. الرسوم والمدفوعات

النسخة الحالية لا تحدد هنا رسومًا أو التزامًا ماليًا عامًا. عند إضافة خدمة مدفوعة يجب عرض السعر وشروط الاسترداد وأي رسوم قبل إتمام الشراء، وتحديث هذه الشروط بما يلزم.

14. حدود المسؤولية

عهد تبذل عناية معقولة في تشغيل الخدمة، لكنها لا تستطيع ضمان صحة كل معلومة يقدمها المستخدمون أو تصرفاتهم خارج المنصة. يجب على المستخدم اتخاذ الاحتياطات المعقولة وعدم إرسال أموال أو وثائق حساسة أو مقابلة شخص في ظروف غير آمنة.

15. إنهاء الحساب

يمكن لصاحب الحساب طلب حذف حسابه من داخل الخدمة. وقد تحتفظ عهد بسجلات محدودة عندما يكون ذلك مطلوبًا نظاميًا أو ضروريًا لمعالجة إساءة أو نزاع مشروع.

16. الملكية الفكرية

اسم AHAD وعهد، تصميم الخدمة، النصوص الأصلية، البرمجيات، والشعارات المملوكة للخدمة محمية بحسب الحقوق المنطبقة. لا يجوز نسخها أو إعادة تقديم الخدمة على أنها تابعة لعهد دون إذن.

17. القانون والاختصاص

يجب استكمال بند النظام الحاكم والاختصاص القضائي باسم الكيان القانوني المسجل قبل التشغيل التجاري واسع النطاق. لا نختلق في هذه الصفحة بيانات قانونية لم تُعتمد بعد.

18. التحديثات

قد تتغير هذه الشروط عند إضافة ميزات أو مدفوعات أو متطلبات تشغيلية. يظهر تاريخ الإصدار أعلى الصفحة، ويُنصح بمراجعتها دوريًا.

هذه نسخة تشغيلية محسّنة وليست بديلاً عن مراجعة قانونية متخصصة. قبل التوسع التجاري يجب إضافة بيانات الكيان القانوني، الاختصاص، عنوان التواصل، وسياسة الرسوم/الاسترداد إن وجدت.
